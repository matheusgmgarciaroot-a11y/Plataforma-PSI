# Mindora - Sistema Inteligente para Psicólogos

Plataforma completa para gestão de clínicas de psicologia, personalizada para a **Dra. Heloisa Valentim**.

## 🎨 Identidade Visual
- **Fundo:** `#FFFFF9` (Cream White)
- **Texto:** `#61401E` (Deep Brown)
- **Estilo:** Moderno, Orgânico, Premium.

## 🚀 Estrutura do Projeto
- `apps/web`: Frontend Next.js 15 (App Router).
- `apps/api`: Backend NestJS.
- `packages/database`: Camada de dados com Prisma ORM.

## ✨ Funcionalidades Implementadas
- [x] Landing Page Mindora Responsiva.
- [x] Dashboard Dra. Heloisa (Sidebar + Header).
- [x] Navegação Funcional entre páginas.
- [x] Lista de pacientes personalizada (Matheus, Ana Julia, Aline, Renato).
- [x] Identidade visual Earth & Cream.

## 🚦 Como rodar
1. Instale as dependências: `npm install`
2. Configure o `.env` na raiz com sua `DATABASE_URL`.
3. Rode o ambiente de desenvolvimento: `npm run dev:web`.
